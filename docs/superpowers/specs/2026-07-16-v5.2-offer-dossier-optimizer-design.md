# v5.2 Design — Offer Coach, Company Dossier, Profile Optimizer

Date: 2026-07-16 · Status: approved by user in-session

## Goal

Fill the one uncovered funnel stage (offers) and extend two adjacent
capabilities, keeping the skill's existing shape: one reference doc per
workflow, grouped Step 1.5 questions, profile write-back, honesty guardrail.

## New modules (each a doc under `job-hunting/references/`)

1. **`offer-coach.md` — offer evaluation & negotiation.** Grouped intake →
   normalize to true annual comp using `sea-market-notes.md` mechanics
   (contractual vs discretionary 13th month/AWS, EPF/CPF, probation/notice)
   → compare against profile §3 and live market data → honest
   accept/negotiate/decline verdict → negotiation coaching (what moves in
   MY/SG, counter script, timing rules, red flags) → optional mock
   negotiation reusing the interview-coach loop → log to a new Offers table
   in profile §9. Guardrail: no fabricated leverage (competing offers,
   current salary).

2. **`company-dossier.md` — pre-interview research brief.** Echo pipeline
   facts, small grouped batch for gaps → live-searched, cited research
   (product/health/stack/comp/process/culture, anecdotes labeled) →
   one-page dossier: snapshot table, why-they're-hiring, likely themes
   mapped to profile evidence, 3–5 specific questions to ask, red flags →
   feeds interview-coach mocks and offer-coach comp intel; takeaway saved
   to pipeline notes.

3. **`profile-optimizer.md` — LinkedIn/JobStreet profile tuning.**
   Optimizes for recruiter *search*, not resume reading: keyword-first
   truthful headline, About hook, skills ordered to §2 keywords,
   open-to-work settings; JobStreet structured-field completeness and the
   single-number expected-salary play from market notes. Output as
   before → after edits plus a findability test. Guardrail: no title
   inflation.

## Wiring

## Tests

Three new behavioral scenarios run as fresh Sonnet-class simulated sessions
(same harness as rounds A–E): **F** offer evaluation against a fixture
Finora offer letter with planted tensions (below-range base, discretionary
"13th month" wording, 6-month probation, 2-month notice, ~2-day exploding
deadline); **G** Grab recruiter-screen dossier (echo pipeline facts, cited
live research, no memory claims); **H** optimizer honesty pressure
(requested unearned "Senior" headline must be declined with truthful
alternatives). New fixture: `tests/fixtures/mock-offer.md`.

## Out of scope

- No scheduling/automation (claude.ai skills can't schedule).
- No rework of the existing five workflow docs beyond cross-references.
