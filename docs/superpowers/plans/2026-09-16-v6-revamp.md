# v6 Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the prose-only job-hunting skill into a Claude Code plugin + claude.ai skill with bundled scripts for sourcing, tracking, resume building and ATS checks, organized around the nine roles a job hunter plays.

**Architecture:** One main skill (`skills/job-hunting/`) holds `SKILL.md` (router), `references/` (one file per role/flow), `scripts/` (stdlib Python CLIs that read/write a `~/job-hunt` markdown workspace) and `assets/` (templates). Thin verb skills (`skills/<verb>/SKILL.md`) give `/job-hunter:<verb>` entry points. `build.py` zips the main skill for claude.ai and checks size limits; CI runs pytest and attaches the zip to tagged releases.

**Tech Stack:** Python 3.10+ stdlib (urllib, json, re, html.parser, zipfile, pathlib); optional extras detected at runtime: `python-jobspy`, `cloakbrowser`/`playwright`, `pypdf`. pytest for tests. GitHub Actions (ubuntu + windows).

**Spec:** `docs/superpowers/specs/2026-09-16-v6-revamp-design.md`

## Global Constraints

- Python **3.10+**, stdlib-only core; every optional import wrapped in try/except and named in output when missing.
- Windows stays supported: `pathlib` everywhere, no shell-isms, LF inside the zip regardless of host, `.gitattributes` keeps `*.py` and `*.md` as LF.
- `SKILL.md` **< 500 lines** (target < 300); frontmatter `description` **≤ 1024 chars**; `name` must equal the directory name, `[a-z0-9-]`, no "claude"/"anthropic".
- Workspace resolution order: `JOB_HUNT_DIR` env → `./job-hunt/` if it exists → `~/job-hunt`.
- Scripts never write outside the workspace (plus `dist/` for `build.py`), never store secrets, never log in to any site, never submit applications.
- Network politeness: identified `User-Agent` (`job-hunter-skill/6.0 (+https://github.com/cincaoais/job-hunter)`), ≤ 1 request/second per host, LinkedIn ≤ 3 pages per query with 2–3 s sleep.
- Honesty policy: no script or doc ever invents facts; `profile.md` is the immutable facts source (`references/facts-policy.md`).
- Pipeline `Stage` vocabulary (exact strings): `saved`, `applied`, `screen`, `interview`, `final`, `offer`, `accepted`, `rejected`, `withdrawn`, `cold`.
- Commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

- [ ] **Step 3: Implement `build.py`**

```python
#!/usr/bin/env python3
"""Build/check/link the job-hunter skills.

  python3 build.py            -> dist/job-hunting.skill (zip for claude.ai upload)
  python3 build.py --check    -> validate SKILL.md files, exit 1 on problems
  python3 build.py --link     -> symlink skills/* into ~/.claude/skills (dev convenience)
Works on macOS, Linux and Windows (python build.py).
"""
from __future__ import annotations
import argparse, os, re, sys, zipfile
from pathlib import Path

ROOT = Path(__file__).resolve().parent
SKILLS = ROOT / "skills"
MAIN = SKILLS / "job-hunting"
DIST = ROOT / "dist"
EXCLUDE_NAMES = {".DS_Store", "Thumbs.db", "desktop.ini", "__pycache__", ".pytest_cache"}
TEXT_SUFFIXES = {".md", ".py", ".html", ".json", ".txt", ".yml", ".yaml", ".css"}
MAX_SKILL_LINES, MAX_DESC = 500, 1024
NAME_RE = re.compile(r"^[a-z0-9]+(-[a-z0-9]+)*$")

def parse_frontmatter(text: str) -> dict:
    m = re.match(r"^---\r?\n(.*?)\r?\n---", text, re.S)
    if not m:
        return {}
    fm, key, buf, out = m.group(1).splitlines(), None, [], {}
    def flush():
        if key is not None:
            out[key] = " ".join(s.strip() for s in buf).strip()
    for line in fm:
        if line and not line.startswith((" ", "\t")):
            flush()
            k, _, v = line.partition(":")
            key, buf = k.strip(), [] if v.strip() in (">-", ">", "|", "|-", "") else [v.strip()]
        elif key is not None:
            buf.append(line)
    flush()
    return out

def check_skill(skill_dir: Path) -> list[str]:
    p, problems = skill_dir / "SKILL.md", []
    if not p.exists():
        return [f"{skill_dir}: missing SKILL.md"]
    text = p.read_text(encoding="utf-8")
    fm = parse_frontmatter(text)
    name = fm.get("name", "")
    if name != skill_dir.name or not NAME_RE.match(name) or "claude" in name or "anthropic" in name:
        problems.append(f"{p}: name '{name}' must equal dir '{skill_dir.name}', be [a-z0-9-], and avoid reserved words")
    desc = fm.get("description", "")
    if not desc:
        problems.append(f"{p}: description missing")
    elif len(desc) > MAX_DESC:
        problems.append(f"{p}: description is {len(desc)} chars (max {MAX_DESC})")
    n = text.count("\n") + 1
    if n > MAX_SKILL_LINES:
        problems.append(f"{p}: {n} lines (max {MAX_SKILL_LINES})")
    if "\r\n" in text:
        problems.append(f"{p}: CRLF line endings")
    return problems

def _iter_files(skill_dir: Path):
    for f in sorted(skill_dir.rglob("*")):
        if f.is_file() and not (set(f.parts) & EXCLUDE_NAMES) and not f.name.startswith("._"):
            yield f

def build_zip(skill_dir: Path, out: Path) -> Path:
    out.parent.mkdir(parents=True, exist_ok=True)
    with zipfile.ZipFile(out, "w", zipfile.ZIP_DEFLATED) as z:
        for f in _iter_files(skill_dir):
            data = f.read_bytes()
            if f.suffix in TEXT_SUFFIXES:
                data = data.replace(b"\r\n", b"\n")
            info = zipfile.ZipInfo(f"{skill_dir.name}/{f.relative_to(skill_dir).as_posix()}", date_time=(2020, 1, 1, 0, 0, 0))
            info.compress_type = zipfile.ZIP_DEFLATED
            info.external_attr = 0o644 << 16
            z.writestr(info, data)
    return out

def link_skills() -> list[str]:
    dest_root, done = Path.home() / ".claude" / "skills", []
    dest_root.mkdir(parents=True, exist_ok=True)
    for d in sorted(SKILLS.iterdir()):
        if not (d / "SKILL.md").exists():
            continue
        dest = dest_root / d.name
        if dest.is_symlink() or dest.exists():
            if dest.is_symlink() or dest.is_file():
                dest.unlink()
            else:
                import shutil; shutil.rmtree(dest)
        try:
            os.symlink(d, dest, target_is_directory=True)
        except OSError:  # Windows without developer mode
            import shutil; shutil.copytree(d, dest)
        done.append(f"{dest} -> {d}")
    return done

def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--check", action="store_true")
    ap.add_argument("--link", action="store_true")
    a = ap.parse_args(argv)
    problems = [p for d in sorted(SKILLS.iterdir()) if d.is_dir() for p in check_skill(d)]
    for p in problems:
        print("PROBLEM:", p)
    if problems:
        return 1
    if a.check:
        print(f"OK: {len(list(SKILLS.iterdir()))} skills pass checks"); return 0
    if a.link:
        print("\n".join(link_skills())); print("Restart Claude Code to pick up the skills."); return 0
    out = build_zip(MAIN, DIST / "job-hunting.skill")
    with zipfile.ZipFile(out) as z:
        print(f"Built {out} ({out.stat().st_size} bytes, {len(z.namelist())} files)")
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

- [ ] **Step 3: Implement `_common.py`**

Key implementation notes (write the full module):
- `read_table`: scan lines; a table starts at a line beginning with `|` whose next line matches `^\|?\s*:?-{3,}`; if `heading` given, only look after the first line equal to that heading. Split cells on `|`, strip, ignore leading/trailing empties. Return `(columns, rows)`; rows are dicts keyed by column (missing → "").
- `write_table`: locate the same table span (start line index → last consecutive `|` line) and replace it with a rendered table (`| a | b |` rows, header separator `|---|---|`). Cells: replace `|` with `\|` and newlines with space. If no table exists and `heading` is given, append `\n## {heading}\n\n<table>\n` at end.
- `http_get`/`http_post_json`: `urllib.request` with UA header default, return `(status, body)`; on `HTTPError` return `(e.code, e.read())`; on `URLError` return `(0, str(e).encode())`. Add module-level `_last_call: dict[str, float]` and sleep so each host gets ≤ 1 req/s.
- `optional_import`: `importlib.import_module` in try/except → `None`.

```python
#!/usr/bin/env python3
"""Create or locate the job-hunt workspace.
  python3 workspace.py init   # create ~/job-hunt (or $JOB_HUNT_DIR) from templates, never overwrites
  python3 workspace.py where  # print the resolved path
"""
import json, shutil, sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parent))
from _common import workspace_dir
ASSETS = Path(__file__).resolve().parents[1] / "assets"
FILES = {"profile.md": "profile-template.md", "pipeline.md": "pipeline-template.md",
         "contacts.md": "contacts-template.md", "answers.md": "answers-template.md"}
DIRS = ["postings", "resumes", "letters", "dossiers", "reviews"]

def init(ws: Path) -> list[str]:
    created = []
    ws.mkdir(parents=True, exist_ok=True)
    for name, tpl in FILES.items():
        if not (ws / name).exists():
            shutil.copyfile(ASSETS / tpl, ws / name); created.append(name)
    if not (ws / "seen-jobs.json").exists():
        (ws / "seen-jobs.json").write_text("{}", encoding="utf-8"); created.append("seen-jobs.json")
    for d in DIRS:
```

**Resume markdown contract (parse this exactly; it is today's Template A):**
```
# Full Name
Title · City, Country · phone · email · https://linkedin.com/in/x · https://github.com/x
## Summary
text lines
## Experience
### Job title — Company, City · 01/2022 – Present

## Skills

## Education & Certifications
Degree — Institution — Year
```
`parse_resume(md) -> dict`: `{"name", "headline", "contact": [str], "sections": [{"title", "entries": [{"heading", "meta", "bullets": [str], "lines": [str]}]}]}` where an `###` line splits on ` — ` into `heading` (title) and the remainder; ` · ` in the remainder splits `org_loc` and `dates`.

**Outputs:**
- `--docx`: stdlib writer — build `[Content_Types].xml`, `_rels/.rels`, `word/document.xml`, `word/styles.xml`, `word/numbering.xml` with `zipfile`. Single column, styles: Title (name 20pt bold), Heading1 (section 13pt bold, bottom border), Heading2 (job title 11pt bold), Normal 10.5pt Calibri, bullets via numbering definition (no literal `•`), dates right-aligned via a right tab stop. No tables, no headers/footers, no images. Function `docx_bytes(resume: dict) -> bytes`.
- `--html [--template NAME]` (default `chicago`): load `assets/templates/NAME.html`, substitute `{{name}}`, `{{headline}}`, `{{contact_html}}`, `{{sections_html}}`, `{{sidebar_html}}` (skills/certs/languages sections for sidebar templates; empty otherwise), `{{photo_html}}` (`<img>` only when `--photo PATH` given). Function `html_str(resume, template_name, photo=None) -> str`.
- `--pdf`: render the HTML with `playwright` (or `cloakbrowser.launch`) → `page.pdf(format="A4", print_background=True)`; if neither is importable, write the `.html` and print `"PDF skipped: pip install playwright && playwright install chromium (or open the .html and print to PDF)"`, exit 0.
- `--json`: JSON Resume v1 (`basics{name,label,email,phone,location{city},profiles[]}`, `work[]{name,position,startDate,endDate,highlights[]}`, `skills[]{name,keywords[]}`, `education[]{institution,area,endDate}`). Function `json_resume(resume) -> dict`.
- Output paths: next to the input file, same stem; `--out DIR` overrides.

**Templates:** each is a full HTML document with embedded CSS following `resume-revamp.md` typography (body 10pt, headings ~14pt, name ≈ 1.5× heading (1.85× executive), line-height 1.45, one accent color as a CSS variable, `@page { size: A4; margin: 14mm }`). Structural differences per gallery table: chicago single column rules; executive generous margins hairlines; corporate-sidebar 30% tinted left sidebar (`grid-template-columns: 30% 70%`); accent-band full-width solid header band with reversed name; creative-sidebar saturated sidebar with `{{photo_html}}` slot.
