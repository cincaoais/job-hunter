# Tech Role Map

Use this to ask the user an informed narrowing question. "Tech" is wide — pin
down the sub-domain, the stack, and the seniority before searching for jobs or
tailoring materials. Ask which area(s) fit best; a person can span more than one.

## Engineering
- **Frontend** — React/Vue/Angular, UI, web performance, accessibility.
- **Backend** — APIs, services, databases (Java, Go, Python, Node, C#, Ruby...).
- **Full-stack** — both of the above.
- **Mobile** — iOS (Swift), Android (Kotlin), or cross-platform (React Native, Flutter).
- **Systems / embedded / low-level** — C/C++, Rust, firmware, kernels.
- **Game development** — Unity, Unreal, engine/graphics.

## Data & AI
- **Data analyst** — SQL, dashboards, BI (Tableau, Power BI, Looker).
- **Analytics engineer** — dbt, data modeling, the transformation layer.
- **Data engineer** — pipelines, Spark, warehouses, orchestration (Airflow).
- **Data scientist** — statistics, experimentation, modeling.
- **ML engineer / applied scientist** — training and shipping models to production.
- **MLOps** — model serving, monitoring, ML infrastructure.
- **AI / LLM engineer** — building on top of foundation models, RAG, agents, evals.
- **Research scientist** — novel ML/AI research (often needs a PhD).

## Infrastructure & Security
- **DevOps / Platform engineer** — CI/CD, IaC (Terraform), developer tooling.
- **SRE** — reliability, on-call, observability, incident response.
- **Cloud engineer** — AWS / GCP / Azure architecture.
- **Security engineer** — appsec, infra security, offensive/defensive.

## Product, Design & Quality
- **Product manager** — roadmap, discovery, prioritization.
- **Product / UX designer** — interaction and visual design.
- **UX researcher** — user research, usability.
- **QA / test engineer** — manual or automated testing, SDET.

## Leadership
- **Engineering manager / director** — leading people and delivery.
- **Tech lead / staff / principal** — senior IC, technical direction.

## Adjacent / non-core-coding tech roles
- **Technical program / project manager (TPM)**
- **Developer advocate / relations (DevRel)**
- **Solutions / sales / forward-deployed engineer**
- **Implementation / customer / support engineer**
- **Technical writer**
- **IT / systems administrator**

## Follow-up questions to ask after they pick an area
1. What's your primary stack / tools within that area?
2. What seniority are you targeting (junior / mid / senior / staff / lead / manager)?
3. Any specialization you want to lean into or move away from?
