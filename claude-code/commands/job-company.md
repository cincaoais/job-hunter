Use the `job-hunting` skill and follow its `references/company-dossier.md` flow to build a one-page, live-searched, cited dossier for this company: **$ARGUMENTS**

First read the candidate profile (skill Step 0/1) so the dossier's "Likely themes" map to the user's real evidence — reuse any existing jd-match extraction. Then research in the doc's decision-value order (product & business, health & news, tech & team, comp intel, interview process, culture) and produce the one-page table plus "Why they're hiring", "Likely themes" (each mapped to profile evidence), and 3–5 researched "Questions to ask".

Everything time-sensitive comes from live web search, never memory; label anything unverified as anecdote. Honor the honesty guardrail — never invent metrics, titles, or achievements. The dossier's themes feed the interview-coach mock (skill Step 4 feed-forward), so keep them concrete. At the end, save the one-line takeaway and red flags to the pipeline tracker and regenerate the updated profile if anything changed.
