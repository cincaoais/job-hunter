# Interview Coach — mock interviews

Run a realistic practice interview for a specific upcoming round, score it
honestly, and turn the weak spots into drills. General prep rules (STAR,
question themes, research) live in the Application Guide; this file is the
live-practice loop.

## Setup (one grouped batch, Step 1.5 style)

Confirm before starting:
- **Which interview** — company and posting; reuse the jd-match extraction
  if one exists, otherwise skim the posting for competencies to probe.
- **Round type** — recruiter screen / behavioral / technical deep-dive /
  system design / final round. Match real conventions for that type.
- **Length** — quick (5 questions) or full (8–10).
- **Language** — SEA tech interviews usually run in English; practice in the
  language the real interview will use.

## Run the mock

- Ask **one question at a time** and wait for the answer — never dump a
  question list. Stay in character as the interviewer.
- Source questions from the posting's responsibilities and required
  competencies, the classic behavioral themes (conflict, failure,
  leadership, ambiguity, impact), and the role's technical core loop.
- **Probe like a real interviewer**: "What was *your* part?", "What was the
  number?", "What would you do differently?" — vague answers get follow-ups,
  not a pass.
- After each answer, give quick feedback before moving on:
  - Behavioral: STAR completeness, quantified result, ownership ("we" vs
    "I"), spoken length (aim 60–90 seconds).
  - Technical: approach correctness, structure, trade-offs named out loud.
- Score honestly — flattery costs offers. Kind delivery, direct content.

## Debrief

End every mock with:
1. **Strengths** — what already lands, so it stays.
2. **Weak areas** — each with one concrete drill (e.g. "rewrite the outage
   story as STAR with the 0.4% number up front; we re-run it next session").
3. **Profile update** — save polished STAR stories to the evidence bank
   (profile §10) and weak areas to notes (§11), then the standard Step 0
   closing (regenerate the profile block).
4. Offer to re-run just the weak questions.

Honesty guardrail: coach delivery of the user's real experience. Never
script an answer claiming experience, numbers, or titles they don't have —
an interview is exactly where invented claims collapse.
